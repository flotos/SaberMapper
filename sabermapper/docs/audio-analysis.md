# Local audio analysis and export timing

`sabermapper.audio.inspect_audio(path)` decodes a local WAV, FLAC, OGG, or MP3 file and returns its exact source SHA-256, decoded sample rate, channel count, frame count, duration, peak, and decoder. No network lookup or filename-based identity is performed. Tags are currently reported as unknown; enter and preserve reviewed title/artist separately in the project/arrangement. SoundFile/Libsndfile is tried first, then the bundled `imageio-ffmpeg` decoder for formats it cannot read. The latter converts to stereo 48 kHz float samples, and this derivative timeline is stated in the decoder field.

`analyze_audio(path, bpm=None, offset_seconds=None)` returns a JSON-compatible report with a 512-bin peak waveform, constant-tempo hypothesis, phase, half/double-tempo alternatives, anonymous 32-beat section windows, energy, accents, rests, and repeat candidates. Agreement is a relative score, not a probability. Silence and sparse onsets return an uncertainty status. Meter and downbeat are not inferred. Check the grid against the exact audio near its start, middle, and end, then save corrections as project data. `timing.BeatGrid` converts beats to seconds and back using `time = offset + beat * 60 / bpm`; variable tempo is not supported.

`prepare_audio(source, destination)` writes OGG Vorbis in bounded chunks and records source/export hashes, decoded frame counts and duration drift, decoder/encoder, and estimated onset shift. It rejects drift over 25 ms or detected onset shift over 40 ms. Encoding is lossy, so manually check the start, middle, and end. `generate_demo_audio(destination)` creates an original 48-second three-section chord, bass, drum, and melody fixture for an end-to-end local trial. Local decode rejects sources over 512 MiB, more than 12 minutes, or over 512 MiB of decoded float samples; the ffmpeg fallback has a 90-second time limit.

Export accepts only decodable OGG Vorbis, checks the final note against decoded duration, and stores the exact source audio hash in `SaberMapper-report.json`. Positive arrangement `audio_offset_seconds` is baked into every exported beat timestamp while `Info.dat` stays at zero offset. Negative offsets are rejected. A 0.5-second offset at 120 BPM therefore moves beat 0 to exported beat 1. No trim or padding is applied during export. Archive names are fixed safe names independent of source filenames. The ZIP's compatibility report records counts, schemas, hashes, duration, and validation limits. Header and decode checks do not establish in-game compatibility, musical timing, or subjective playability; inspect in the editor and game.

The relevant format and audio references are the [BSMG map format](https://bsmg.wiki/mapping/map-format.html), [BSMG Info fields](https://bsmg.wiki/mapping/map-format/info.html), [SoundFile documentation](https://python-soundfile.readthedocs.io/en/0.13.1/), [imageio-ffmpeg binary lookup](https://github.com/imageio/imageio-ffmpeg/blob/main/imageio_ffmpeg/_utils.py), and [SciPy peak detection](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html).
